# 变量与数据类型

变量和数据类型是编程的基础概念，理解它们对于掌握任何编程语言都至关重要。

## 什么是变量？

变量是存储数据的容器，它有一个名称和对应的值。可以把变量想象成一个贴有标签的盒子，盒子里存放着某种数据。

### 变量的特性
- 名称（标识符）
- 值（存储的数据）
- 类型（数据的种类）
- 作用域（变量可见的范围）
- 生命周期（变量存在的时间段）

## 常见数据类型

### 基本数据类型
- **整数** - 如 1, 42, -7
- **浮点数** - 如 3.14, -0.001
- **布尔值** - true/false 或 1/0
- **字符** - 单个字符，如 'a', '7'
- **字符串** - 文本，如 "Hello World"

### 复合数据类型
- **数组/列表** - 有序集合，如 [1, 2, 3]
- **元组** - 不可变的有序集合
- **字典/映射** - 键值对集合，如 {"name": "John", "age": 30}
- **集合** - 无序不重复元素集合
- **对象** - 面向对象编程中的实例
