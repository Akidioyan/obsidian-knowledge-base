# 运算符与表达式

运算符是编程语言中用于执行特定操作的符号，而表达式是由变量、常量和运算符组合而成的代码片段，它们共同构成了程序的计算逻辑。

## 运算符类型

### 算术运算符
- 加法 (+)
- 减法 (-)
- 乘法 (*)
- 除法 (/)
- 取模/求余 (%)
- 幂运算 (**)
- 整除 (//)

### 比较运算符
- 等于 (==)
- 不等于 (!=)
- 大于 (>)
- 小于 (<)
- 大于等于 (>=)
- 小于等于 (<=)
- 恒等（严格相等）(===) - 某些语言特有

### 逻辑运算符
- 与 (AND, &&)
- 或 (OR, ||)
- 非 (NOT, !)

### 赋值运算符
- 基本赋值 (=)
- 复合赋值 (+=, -=, *=, /=, %=)

### 位运算符
- 按位与 (&)
- 按位或 (|)
- 按位异或 (^)
- 按位取反 (~)
- 左移 (<<)
- 右移 (>>)

### 其他运算符
- 条件/三元运算符 (? :)
- 成员运算符 (in)
- 身份运算符 (is)
- 位移运算符

## 表达式

### 表达式类型
- 算术表达式
- 关系表达式
- 逻辑表达式
- 字符串表达式
- 位表达式

### 表达式求值
- 运算符优先级
- 结合性（左结合与右结合）
- 使用括号明确优先级
