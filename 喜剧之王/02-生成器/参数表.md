# 参数表 v0.1（首轮最小闭环）

> 按 2026-11-25 决定：参数表只留 **角色 × 场景 × 时长档**。
> 先跑通闭环，再按数据决定要不要加字段。

## 三个字段

| 字段 | 取值来源 | 本轮取值 |
|---|---|---|
| `角色` | 角色圣经 | C01 恶兽（唯一） |
| `场景` | [[三库]] 生活憋屈库 | S02 / S04 / S06 / S07 / S08 |
| `时长档` | 6 / 15 / 30 秒 | 15s（唯一） |

**为什么是这三个**：爆款要能反查，最少要知道「谁、在哪、多长」。角色决定一致性，场景决定共鸣，时长决定结构。其余字段先不进表。

## 机制的处理（本轮降级为变体开关）

3 个反差机制仍参与生成，但**不进参数表字段**，只作为产出素材表里的一列标签：

| 机制 | 用途 | 选它的理由 |
|---|---|---|
| M01 身份错位 | 变体 A | 视觉反差强，不依赖台词 |
| M03 尺度错位 | 变体 B | 史诗级严肃处理小事，最易做升级链 |
| M05 自洽的错误逻辑 | 变体 C | 角色最稳，疯感来源 |

排除 M02 语境移植（需要第二层世界观设定，15s 讲不清）、M04 情绪错位（偏台词）、M06 后果升级（它是结构模板，不是反差引擎）。

> 一周后用实测数据决定：若某机制稳定胜出，再把它升格为正式参数字段。**没数据之前不扩字段。**

**v2 补充（参考成熟作品后）**：《Presto》双帽、塔蒂碎玻璃门、憨豆 Mini 的共同点是「一个设定建立后，所有笑点都是它的推论，只需新落点，不需新点子」〔[[拆片档案]] §7〕。本项目的笑点机器是 C01 的三条公理，场景只是新落点，不是用来「撞机制」的自变量。因此 v1 用「机制 × 场景」笛卡尔积批量出稿的方向偏了，[[生成模板]] 的 T2 已改写。**机制字段更不该急着升格**。

## 素材 ID 规范（v0.1）

`C01-S07-15-020` = 角色 - 场景 - 时长档 - 序号。
同 setup 的 3 个机制版本归入同一**版本组** `V01`，用于横向 A/B。

```
1 角色 × 3 机制 × 5 场景 × 2 条 = 30 条
```

## 角色圣经（比剧本重要）

AI 视频最贵的是**角色一致性**；喜剧尤其依赖「角色非常认真」。角色一崩，疯感就塌。

### C01 恶兽（本轮定稿）

- 想成为：让人闻风丧胆的反派
- 最怕：被夸「可爱」「靠谱」
- 想伪装成：威严、冷酷、不可接近
- 错误逻辑：所有善意都是畏惧的伪装，所有意外都是高阶试探
- 绝不承认：自己其实在配合所有人
- 外部标志：固定的一对角 + 深色披风 + 永远严肃的表情
- **铁律**：绝不挤眉弄眼、绝不看向镜头、绝不解释笑点

> 写不出来时别想「怎么好笑」，问：他最怕什么？他越认真，会发生什么灾难？

### 升级链模板（15s 压缩版）

```
0–3s 钩子 → 3–5s 建立规则 → 5–8s 第一次违背 → 8–11s 放大
→ 11–13.5s 失控 → 13.5–14.5s 回收 → 14.5–15s 片尾回钩
```

## 五个场景（全部选「视觉友好、静音可懂」）

| ID | 场景 | 为什么选它 |
|---|---|---|
| S02 | 同事说「我帮你看看」，消失三天 | 时间是纯视觉的，不需要任何台词 |
| S04 | 朋友说帮你砍价，自己买了一件 | 一件衣服即可完成反转 |
| S06 | 群里发消息，全员已读不回 | 手机界面就是道具，成本最低 |
| S07 | 外卖显示骑手已到达，人不在 | 一扇门 + 一个空镜，跨文化通用 |
| S08 | 为省 3 块运费凑单凑到 200 元 | 购物车数字 + 商品堆叠，视觉即笑点 |

S001/S003/S005 本轮排除：反转全在台词里，静音播放会死。

## 时长档（本轮只用 15s）

| 档 | 结构 | 本轮 |
|---|---|---|
| 6s | 单点反转，无升级链 | 不用 |
| 15s | 三翻四抖压缩版 | **本轮唯一档位** |
| 30s | 完整升级链 | 不用 |

只跑一档是为了控制变量：同角色、同场景、同时长，只换机制，A/B 才测得出东西。

## 参数表之上还有故事地基

参数表只回答「谁、在哪、多长」，**不回答「他为什么必然这么干」**。
后者见 [[C01-角色故事设定]]：世界已不怕他，他把一切善意解释成恐惧，且这套逻辑无法被证伪。
每条梗生成前先过 [[生成模板]] 的 T0 故事一致性检查，答不上来的不进批次。

因此 v0.1 的三字段是**够用**，不是**完整**。是否加字段由实测决定，故事层则永远在参数层之前。

## 结构配比

70% 结构性 / 20% 共鸣 / 10% 时效梗。本轮时效梗为 0。
