# 生成模板 v2

> 模板固定，只换参数。v2 依据 [[拆片档案]] 修正了三处：可读性契约、加工流畅度、以及「笑点机器」取代笛卡尔积。

## 一、买量硬约束（写进每条提示词，不要事后补）

| 字段 | 要求 | 依据 |
|---|---|---|
| 前 3 秒 | 必须有可见钩子或异常画面，不许铺垫 | 项目约束 |
| **可读性契约** | 3 秒内让观众看清「**目标 / 障碍 / 角色在哪**」三要素；宽景、全身、道具清楚 | 基顿远景长镜、阿特金森「整个身体才重要」、S8〔[[拆片档案]] §2/§1〕 |
| **加工流畅度** | 笑点不能藏在糊画面、小字、需暂停细看的动作里；越容易加工越好笑 | 哈佛商学院出版近 1300 人／6 实验〔§10〕 |
| 静音可懂 | 笑点能被画面单独读出，台词只是加分项 | 项目约束，已被上一条升级 |
| 画幅 | 9:16 竖屏 | 项目约束 |
| 角色数 | 1–2 个，单场景优先（AI 生成一致性与成本） | 项目约束 |
| 时长档 | 6s 单点反转 / 15s 铺垫充分 + 第四拍可圆 / 30s 完整后果链；**升级次数不固定** | 三翻四抖「三」是约数，唯一标准是铺得平垫得稳〔§9〕 |
| 片尾回钩 | 0.5–1s 统一视觉钩子挂回游戏，不解释剧情 | 项目约束 |
| 审核 | 不出现误导性玩法演示、不碰平台红线 | 项目约束 |
| 可 A/B | 同一 setup 至少出 3 个不同机制的 punchline 版本 | 项目约束 |

## 二、固定负面约束（规则号对应 [[三库]]）

```
禁止准备不足：先立住目标/障碍/角色位置，再写反转。
禁止反转圆不回来：观众必须能在 1 秒内自己把前后说通，不为转而转。
禁止任何解释性台词；笑点之后立刻打住，不补尾巴。
禁止角色朝镜头挤眉弄眼或"演搞笑"；角色必须非常认真、不自知、绝不看镜头。
禁止谐音梗做主体；时效梗上限是经验假设 10%，不是规则。
禁止画面糊、字太小、动作看不清、需要暂停理解。
禁止需要第二层设定才懂的笑点。
禁止删掉后不影响人物或情节的"外插花"包袱。
禁止用并列段子凑时长，必须是后果链，每一拍比上一拍更难收回。
同一批次内，跪姿 / 敬礼 / 沙盘 / 摆贡品 / 受降仪式各只允许出现 1 次。
一条片里最多 1 个仪式化动作，第二个开始是重复不是升级。
```

## 三、生成范式：笑点机器，不是笑点清单

> v1 的 T2 用「机制 × 场景」笛卡尔积批量出稿，产出的是**并列段子**。
> 《Presto》双帽、塔蒂碎玻璃门、憨豆 Mini、肖恩羊群伪装的共同点是：**一个设定建立后，所有笑点都是它的推论，只需新落点，不需新点子**〔[[拆片档案]] §7〕。

本项目固定的「笑点机器」= [[C01-角色故事设定]] 的三条公理：
善意都是畏惧的伪装 / 冷淡都是最高级臣服 / 顺利都是高阶试探。

因此生成顺序改为：

```
固定角色世界观（不变） → 选一个新落点（场景/物件/系统提示）
→ 推演「按他的公理，这件事必然被解释成什么」
→ 让这个解释自己长出后果链 → 结尾记一笔档案
```

场景不是用来「撞机制」的，是用来**给同一套错误逻辑提供新落点**的。

## 四、提示词模板

### T0 故事一致性检查（每条梗生成前先过一遍）

```
读取 [[C01-角色故事设定]] 的三条公理与「绝不醒悟机制」。
对给定落点，先回答：以他的错误逻辑，这件事会被解释成什么？
再回答：他最怕什么？他越认真，会发生什么灾难？最后会发生什么"顺利得不像话"的结果？
写完后自检：
  - 有没有出现「他终于明白了」？（出现即作废）
  - 有没有出现解释性台词？（出现即作废）
  - 观众是否比角色先知道真相？（否则作废，见 M10 预知灾难）
  - 输出的梗能否挂回《敌方示弱档案》的那一笔记法？
```

### T1 一铺垫多反转（练摆脱第一反应）

```
给定 setup 与角色的错误逻辑，写 8 个不同的 punchline。
1. 前 3 个通常是第一直觉，第 5 个以后必须明显更意外；
2. 每个 punchline 只用画面和动作表达，不解释；
3. 反转强度取中等，必须能被观众 1 秒内圆上（Suls 倒 U 型）；
4. 角色全程认真、不自知；
5. 每条标注：机制 ID / 是否静音可懂 / 加工成本（低·中·高）。
输出：ID | punchline | 机制 | 静音可懂 | 加工成本 | 画面描述。
```

### T2 落点批量出稿（v2.1 文本优先改写）

```
从 [[文本素材库]] 取 <N> 条已通过「复述测试」的文本梗（A 类结构文本 / B 类画面文字），
不要凭空生成新梗，也不要从表演依赖型作品里搬桥段。
固定 C01 的三条公理不变：对每条文本梗，写出"他必然如何误读它"，
再让这个误读自己长出后果链。机制是同一个，文本梗是变量。
每条先自检：去掉角色名、不看任何画面，这两句话还笑得出来吗？笑不出来即退回素材库。
每条输出：素材ID | 来源T-ID | 他的误读 | 后果链 | 观众先看见的真相 | 前3秒钩子 | 加工成本。
不要自评好坏，不要打分，先把供给做够。
```
> 素材是文本，成片只是文本的一次渲染。文本可检索、可版本化、可按 ID 回流；视频不能。

### T3 扩写成短片结构

```
把梗 <素材ID> 扩写成 <15/30>s 竖屏短片分镜。
结构：0–3s 立住目标/障碍/角色位置 → 铺垫（次数依充分程度而定，不写死三次）
→ 后果链逐级放大 → 第四拍或最后一拍反转（必须能被观众自己圆上）
→ 结尾回收 → 片尾回钩 0.5s。
输出：秒数 | 画面 | 动作 | 台词（可为空）| 音效 | 备注。
硬要求：宽景可读、全身入画；全程静音可懂；删掉任何外插花；角色不解释笑点。

密度自检（见 [[笑点密度基准]]，3–5 分钟短片）：
  - 有效包袱数 ≥ 时长(分钟) × 4；3'40" → ≥15 个；
  - 任意相邻包袱间隔 ≤20 秒；每 5–8 秒一个视觉/信息变化点（剪辑层另查）；
  - 0–3 秒钩子、15 秒左右一次升级、25 秒前一次大回报；
  - 强度阶梯式增强，最响的不放在前 30 秒；留 15–30 秒情绪低谷；
  - 每个包袱过 [[文本素材库]] 的复述测试，且不与别的包袱共用铺垫。
  加密靠「同一错误逻辑每 12–15 秒产一次新结论」（《卖拐》受骗链 / 《昨天今天明天》语义曲解链），
  不靠并列多塞段子。
```

## 五、产出文件规范

每批存到 `04-产出/YYYYMMDD-批次号/`，至少包含：

- `素材表.md`：T2 原始表格（全量保留，包括被淘汰的）
- `入选.md`：通过筛选的条目 + 理由
- `分镜/`：T3 脚本，文件名用素材 ID
- `故事/`：角色设定与完整剧本（第 0 层，先于参数）

**不要删掉垃圾稿**。淘汰记录是判断力训练的数据。

## 六、关于「解释太多」

```
解释：他以为自己很帅，其实很丑。
喜剧：他对着镜子整理发型，镜子裂了。他说：「果然，太帅会伤人。」
```
解释会把认知事件降格成内容，观众自行完成的那一跳一旦被说破，笑就过去了。生成后统一做一遍「删解释」检查。
