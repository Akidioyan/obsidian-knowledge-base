# V01 · S07「外卖显示骑手已到达，人不在」三版本分镜

**A/B 控制变量**：同角色 C01、同场景（自家门口）、同 15s、同片尾回钩、同无对白。
**唯一变量**：反差机制。A=M01 身份错位／B=M03 尺度错位／C=M05 自洽的错误逻辑。

> **完整故事在 `故事/` 目录，本文件只是镜头表**：
> [[C01-角色故事设定]]（系列地基）· [[S07-完整故事]]（30s 完整剧本）· [[V01-三版本故事]]（三版叙事体文本）。
> A/B 真正测的不是「哪个动作更好笑」，而是「哪种错误逻辑更让人上头」。

## 固定角色提示词（每个镜头都要带，保证一致性）

```
人形恶兽，一对弯曲的深色角，深色长披风，身形高大，面部永远严肃，绝不笑，
绝不看向镜头，不挤眉弄眼。动作缓慢、克制、郑重，像在执行一项极重要的仪式。
竖屏 9:16，单一门口场景，自然室内光，固定机位中景为主，手机界面用特写插入，
每镜头 2–3 秒硬切，不用推拉摇移特效。无对白、无旁白、无字幕、无夸张卡通表情。
喜剧靠动作与构图，不靠表演幅度。
```

## 固定片尾回钩（三版完全一致）

```
14.5–15s：右下角淡入一个固定小角标（方块轮廓 + 角色剪影），0.5 秒，
不加文字、不加音效、不解释剧情、不遮挡主体。
```
目的是让喜剧系列能挂回游戏，但不破坏笑点、不演示玩法、不碰误导性素材红线。
