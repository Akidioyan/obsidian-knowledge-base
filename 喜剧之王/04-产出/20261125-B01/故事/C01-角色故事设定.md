# 末代恶兽（C01）· 完整故事设定

> 一句话：**世界已经不怕他了。为了继续当反派，他把一切善意都解释成恐惧。**

这是整个系列的地基。之前只有 6 个字段的角色卡，缺的就是这一层——
没有它，那些反转只是动作；有了它，观众会知道「他这个人，必然会这么干」。

---

## 一、前史：他是被「没人害怕」打败的

他曾经是某个史诗世界里最后一只恶兽。专职让人闻风丧胆，做得很好，好到成了本职工作。

后来那个世界结束了。不是被勇者讨伐，不是被封印，是**大家慢慢不再怕他**：
勇者开始通勤，魔王改做绩效，村民在他面前放下武器，递来一张访客登记表，请他「稍微等一下」。
没有人尖叫，没有人逃跑。最伤的是那句「谢谢您配合」。

他站在原地想了很久，得出了一个能让自己继续活下去的结论：
**他们不是不怕，是怕到了极点，所以不敢表现出来。**

于是他追踪「世上最后一丝恐惧」离开故乡，来到一片看起来毫无异常的居民区。
在他眼里，这里是敌方的核心防区：每个人都有条不紊，每个人都礼貌，每个人都假装没看见他的角。
越平常，越可疑。越客气，越说明对方段位极高。

他就这样住下了，开始了一场漫长的征服。

## 二、他的三条公理（错误世界观，全片不许被推翻）

1. **所有善意都是畏惧的伪装。** 帮忙、让座、打折、发券，都是敌方在示弱求和。
2. **所有冷淡都是最高级别的臣服。** 已读不回、无人现身、消息石沉大海，说明对方连反抗都不敢打字。
3. **所有顺利都是针对他的高阶试探。** 事情办得太顺，一定是因为敌人在暗处布了更深的局。

这三条构成一个**无法被证伪**的闭环：无论发生好事坏事，都只能证明他是对的。
这也是这个角色能一直拍下去的原因——**他永远等不到醒悟的那一刻**，因为醒悟需要证据，而他的系统会把任何证据都吃掉。

## 三、他最怕的，以及怕的时候会做什么

最怕被人说「可爱」「靠谱」「谢谢您」。
因为这类话里找不到一丝恐惧，他的整套解释会当场塌掉。

所以他从不反驳、从不生气。他会立刻**用一个更郑重的仪式，把这件事重新解释成高阶恐吓**：
缓缓点头，掏出小本子记一笔，或者行一个更标准的礼。
他越严肃，观众越清楚他在拼命撑住一个已经不成立的世界。**这就是疯感的来源，不是他演得夸张。**

## 四、随身道具：《敌方示弱档案》

一本深色封皮的小本子。每集结尾他都摊开它，郑重记一条极短的字：

- 「第 41 号对手，未战先退。疑为敬我。」
- 「第 42 号，赠券五元，示弱。」
- 「第 43 号，三人不回，全境归顺。」

作用有三：
1. **系列回钩**——每集最后那一笔，观众会等下一集他又要记什么。
2. **可回收梗**——某集可以让他翻回第一页，发现记的全是同一批邻居。
3. **静音友好**——四个到八个字的大特写，竖屏看得清，不需要任何台词。

## 五、每集的通用故事骨架（系列引擎）

```
他发现一件小事，判定为「高阶试探」
  → 用史诗级规格认真应对
  → 事情顺利得不像话
  → 他把顺利解读成「敌方已投降」
  → 郑重记进《敌方示弱档案》
  → 观众看到的却是：他刚帮人做了件小事 / 被系统当成普通用户 / 被礼貌地忽略了
```

**关键**：观众始终比他多知道一点。他不是傻，他是把全部智力都用在维护一套歪理上。
每集都不许出现「他终于明白了」——一旦明白，系列就结束了。

## 六、为什么场景是外卖、群聊、凑单、砍价、等同事

这些不是随便挑的生活场景，在他的世界观里它们是**敌占区的日常防线**：
- 外卖显示「已到达」却没人 → 隐身刺客
- 八人已读零回复 → 全境归顺
- 满减与优惠券 → 敌方求和文书
- 同事说「我帮你看看」后消失 → 潜伏任务
- 店员请他试穿 → 招安仪式

**现代生活越琐碎，他的史诗感越荒诞。** 尺度错位不是靠台词堆出来的，是靠这个人本身撑出来的。

## 七、配角规则

邻居、同事、店员、骑手都只出现背影、局部或一瞬间的表情，**从不给正脸、从不给台词承担笑点**。
原因：一是 AI 视频生成的一致性成本（只维护 1 个角色），二是他们在这个系列里本就不重要——
他们是「敌方」，而故事只关于他怎么解释敌方。

## 八、表演铁律（不可破）

- 绝不笑、绝不挤眉弄眼、绝不看向镜头
- 动作比常人慢半拍，每个动作都有起势和收势
- 不解释笑点，不吐槽，不设置「拆台角色」
- 披风与角永远整齐，哪怕在追一只被风吹走的塑料袋
- 所有台词／字幕都是可选的，去掉后笑点必须仍然成立

## 九、角色一致性提示词（更新版，含故事气质）

```
人形恶兽，一对弯曲的深色角，深色长披风，身形高大，面部永远严肃、克制、略带疲惫，
绝不笑，绝不看向镜头。动作缓慢郑重、慢半拍，每个动作有起势和收势，
像一位仍在执行旧时代使命的将军，而不是在搞笑。
随身一本深色封皮小本子。竖屏 9:16，自然室内光，固定机位中景为主，
每镜头 2–3 秒硬切，不用推拉摇移特效。无对白、无旁白、无夸张卡通表情。
```

## 十、目前可回收的梗

| 埋梗 | 回收方式 |
|---|---|
| 《敌方示弱档案》 | 每集结尾记一笔；若干集后翻回第一页 |
| 那对从不摘下的角 | 某集过门框时卡住，他仍保持仪态 |
| 「第 N 号对手」编号 | 编号涨到很大时，观众发现全是同一个人 |
| 片尾统一角标 | 系列资产，挂回游戏但不解释剧情 |
