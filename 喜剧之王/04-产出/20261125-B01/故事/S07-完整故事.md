# 《最后的恐惧》第 1 集：骑手已到达

系列地基见 [[C01-角色故事设定]]。这一集是整个系列第一次把他的世界观完整演出来。

---

## 故事

末代恶兽住进这栋居民楼的第 41 天，手机第一次给了他一个像样的消息：

> 骑手已到达。

他盯着那行字看了很久。终于来了。一个对手，敢在尚未露面的情况下，就宣告自己已经抵达他的门前。
这不是送餐，这是宣战。而且规格极高——**先报位置，不出面**，分明是让他知道：我在，你看不见我。

他整了整披风，把角上沾的一点灰拂掉，像出征前那样把钥匙在桌上摆正。
然后推开门。

走廊空无一人。灯是感应的，亮了一下，又灭了。

换作别人，会以为外卖放错了地方，或者骑手走错了楼层。
他没有。他缓缓点了点头：能在我眼皮底下现身却不被看见，这是最高段位的刺客。
**世上果然还有人怕我，怕到不敢露面。**

于是他按接待刺客的规格回礼。

他把餐费一张张理齐，端端正正摆在门槛前的地上，退后一步，对空走廊深深拱手。
风从楼道口灌进来，吹走了一张纸币。他没有去追，连眼睛都没多动一下，只是又退了三步，
比刚才更恭敬——**对方连风都调得动，段位还在往上走**。

他就这么保持着拱手的姿势，倒退着进门，缓缓把门带上，全程没有转身。
不给对手任何被识破的难堪。这是他理解的体面。

门合上了。

镜头留在门外，没有跟进去。一只餐盒从头到尾都挂在门把上，随着关门轻轻晃了一下。
它一直在那儿。在他拱手的时候，在他退三步的时候，在他小心不转身的时候。
他一次也没看见。

屋里，他摊开那本《敌方示弱档案》，蘸着郑重写下第八个字：

> 「第 41 号对手，未战先退。疑为敬我。」

写完，他把本子合上，双手压平，坐姿比刚才更端正了一些。
今天，他确认了一件事：这个世界，还在怕他。

（片尾 0.5 秒，右下角统一角标淡入。不解释剧情。）

## 为什么这才算「完整的故事」

| 要素 | 落在哪 |
|---|---|
| 人物动机 | 他在找「世上最后一丝恐惧」，已找了 41 天 |
| 触发事件 | 手机报「骑手已到达」，一个人没露面就宣告抵达 |
| 他的解释 | 不是送错了，是隐身刺客、高阶宣战 |
| 升级链 | 摆正钥匙 → 拱手 → 摆贡品 → 退三步 → 不转身，越来越郑重 |
| 反转 | 餐盒一直挂在门把上，观众看见，他始终没看见 |
| 回收 | 翻开《敌方示弱档案》，记下「第 41 号」——回到开头的 41 天 |
| 余味 | 他坐得比刚才更端正：这一天他更确信世界还在怕他 |

之前那版 15s 分镜只有「升级链 + 反转」，缺了动机和回收，所以读起来像动作段子，不像故事。
**观众可以不知道他的前史，但创作者必须知道**——知道之后，每一个动作才有必然性。

## 15s 压缩版怎么砍（买量投放用）

保留 **0–3 钩子、9–12 确认段位、16–20 退三步、24–27 门把反转、29.5–30 回钩** 五段，压成：

```
0–3 对空走廊深深拱手 → 3–6 手机「骑手已到达」，缓缓点头
→ 6–9 摆贡品、被风吹走一张、再退三步 → 9–12.5 保持拱手倒退进门、不转身
→ 12.5–14.5 门合上，餐盒在门把上晃动 → 14.5–15 角标
```

砍掉的是钥匙和档案。档案那一笔移到系列第 2 集开头补，做成跨集回收。
**砍的是镜头，不是故事**——角色动机仍在，只是不演出来。这就是 15s 和 30s 的区别。
