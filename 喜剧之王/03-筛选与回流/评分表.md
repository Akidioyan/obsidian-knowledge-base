# 分层筛选：四道关，别用一张评分表

> 关键前提：**AI 自评不能当筛选器**。LLM 会给几乎所有结构完整的稿子打 4 分，
> 它只认得「像不像好笑」，不认得「好不好笑」。自评只用于粗筛去重。
> v2 依据 [[拆片档案]] 补了三条 L0 硬砍与 L3 的三分计数口径。

## L0 硬约束一票否决（最先做，AI 可做）

命中任意一条直接删，不打分、不抢救：

- [ ] **3 秒内没让观众看清「目标 / 障碍 / 角色在哪」**〔可读性契约，基顿／阿特金森／S8〕
- [ ] **画面糊、字太小、动作看不清、需暂停理解**〔加工流畅度，HBR 近 1300 人／6 实验：越容易加工越好笑〕
- [ ] **反转圆不回来**：观众 1 秒内找不到把前后说通的解释〔Suls 倒 U 型；《海燕》馊包袱〕
- [ ] 静音看不懂（笑点只在台词里）
- [ ] 前 3 秒没有可见钩子
- [ ] 角色超过 2 个 / 场景超过 1 个
- [ ] 需要解释或第二层设定才懂
- [ ] 角色自己解释笑点 / 笑点后还补尾巴 / 朝镜头演搞笑
- [ ] **外插花**：删掉后不影响人物或情节的包袱〔陈佩斯「创造笑声是出发点，而非手段」〕
- [ ] 谐音梗、网络热梗做主体
- [ ] 无片尾回钩 / 有审核风险
- [ ] 与已入选条目语义重复（老梗换皮）

## 节奏硬指标（v2.1 新增，见 [[笑点密度基准]]）

按「抖响的有效包袱」口径，3–5 分钟短片：

- [ ] 有效包袱数 ≥ 时长(分钟) × 4（3 分钟 ≥12 / 5 分钟 ≥20）
- [ ] 任意相邻包袱空窗 ≤20 秒
- [ ] 0–3 秒钩子、15 秒左右一次升级、25 秒前一次大回报
- [ ] 强度阶梯增强，最响的不在前 30 秒用掉
- [ ] 有 15–30 秒情绪低谷；没有两个包袱共用同一个铺垫

> 密度有上限：Atlantic「中间区」、Ken Levine「三处真诚的大笑胜过二十个俏皮话」、
> OnBuy 120 人实测 TBBT 每小时真实笑出仅 6 秒。超过 5–6/分钟会疲劳，不是越多越好。

## L1 去重（AI 可做）

语义聚类，同一 setup 同一机制只留 1 条；把「第一直觉」型反转整批降权。
**保留淘汰清单**，写进本文件末尾，供 [[三库]] 更新淘汰规则。

## L2 结构检查（人 + AI 对照，六项 1–5 分）

| 项目 | 说明 | 阈值 |
|---|---|---|
| 共鸣度 | 会不会觉得「这不就是我吗」 | ≥3 |
| 原创度 | 是不是老梗换皮 | ≥3 |
| 疯感 | 角色是否认真执行荒诞逻辑、始终不自知 | ≥4（最关键） |
| 可拍性 | 单场景、静音可懂、AI 低成本能稳定生成 | ≥4 |
| 可回收性 | 能否埋梗、结尾翻出来 | ≥3 |
| 加速度 | 是后果升级链，不是并列段子 | ≥4 |

时效依赖另算：越依赖短期热梗越该砍，不做加分项。
**低于阈值直接删，不要救。** 写不好喜剧往往不是写不出来，是舍不得删。

## L3 真实信号（必须做，AI 替代不了）

同一个 setup 出 3 个版本（各用不同反差引擎），小成本实测。不看点赞，看：

- 用户有没有**复述**某句话
- 用户有没有**玩梗**、二创
- 有没有说「这不就是我吗」
- 有没有催更这个角色

**v2 新增：三分计数**〔HCI 语境依赖手册〕。幽默不给部分分数——只有三种结局：解码成笑 / 解码成噪音（没懂）/ 解码成冒犯。按人群分别统计这三项，**任一人群出现「被冒犯」即淘汰该条**，不靠总点赞掩盖。

评论区复述率比点赞更能预测一个梗能不能成为 IP 资产。
成片投放后看 3s 完播 / 完播率 / CTR / CPA → 回填 [[数据回流]]。

## 四层的关系

```
L0 砍掉不合格的  →  L1 砍掉重复的  →  L2 砍掉平庸的  →  L3 让真人/市场裁决
```
50 条 → L0 剩 15 → L1 剩 10 → L2 剩 5 → L3 选 3 条做成片。

先大量，再筛选。大量创作的本质是允许自己写 100 条垃圾，从里面捞 5 条能用的。
